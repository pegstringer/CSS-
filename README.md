# 🎨 CSS Garden - 楽しくCSSを学ぼう！

インタラクティブなゲーム形式でCSSを学べる学習アプリです！

## ✨ 特徴

- 🎯 **10段階のチャレンジ**: 基礎から応用まで段階的に学習
- 📚 **詳しい解説**: 各CSSプロパティを初心者にも分かりやすく解説
- 💡 **段階的ヒントシステム**:
  - 📚 詳しい解説 - プロパティの使い方とよくある間違い
  - 💡 ヒント - 具体的なコード例
  - 👀 答えを見る - 完全な解答例
- 🎨 **リアルタイムプレビュー**: コードを書いたらすぐに結果が見れる
- 🎉 **楽しいUI**: カラフルでアニメーション豊富なインターフェース
- ⚠️ **よくある間違いの解説**: 初心者がつまずきやすいポイントを明示
- 📱 **レスポンシブ対応**: スマホでもPCでも快適に学習

## 🎓 学べるCSSプロパティ

1. **color** - 文字色の変更（テキストを赤く）
2. **font-size** - テキストサイズの調整（絵文字を大きく）
3. **background-color** - 背景色の設定（ボックスを黄色に）
4. **padding** - 内側の余白（ゆったりスペース）
5. **text-align** - テキストの配置（中央揃え）
6. **border-radius** - 角丸の作成（優しい見た目）
7. **text-shadow** - テキストに影をつける（立体的に）
8. **border** - 枠線の設定（囲みをつける）
9. **transform** - 要素の変形（45度回転）
10. **linear-gradient** - グラデーションの作成（美しい色の変化）

## 🚀 使い方

1. ブラウザで `index.html` を開く
2. チャレンジの説明を読む
3. CSSエディタでコードを書く
4. 「✨ 適用する」ボタンでプレビュー
5. 「✅ チェック」ボタンで正解確認
6. 次のレベルに進む！

## 💻 技術スタック

- HTML5
- CSS3 (グラデーション、アニメーション)
- Vanilla JavaScript (フレームワーク不要)

## 🎮 遊び方のコツ（初心者向け）

1. **まずは解説を読もう**: 「📚 詳しい解説」ボタンでプロパティの基本を理解
2. **よくある間違いをチェック**: ❌ と ✅ で正しい書き方を確認
3. **ヒントを活用**: 「💡 ヒント」で具体的なコード例を見る
4. **自分で書いてみる**: CSSエディタにコードを入力
5. **プレビューで確認**: 「✨ 適用する」ボタンで結果を見る
6. **正解チェック**: 「✅ チェック」で合っているか確認
7. **困ったら答えを見る**: 「👀 答えを見る」で完全な解答を確認
8. **やり直しOK**: 「🔄 リセット」でいつでもやり直せる

### 💡 学習のポイント

- **焦らず一歩ずつ**: 各レベルをしっかり理解してから次へ
- **間違いを恐れない**: 何度でもトライできます
- **実際に試す**: 解説を読むだけでなく、必ず自分で書いてみよう
- **プレビューを見る**: 数値を変えてみて、どう変化するか試してみよう
