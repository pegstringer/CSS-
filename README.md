# 🎨 CSS Garden - 楽しくCSSを学ぼう！

インタラクティブなゲーム形式でCSSを学べる学習アプリです！

## ✨ 特徴

- 🎯 **10段階のチャレンジ**: 基礎から応用まで段階的に学習
- 🎨 **リアルタイムプレビュー**: コードを書いたらすぐに結果が見れる
- 💡 **ヒント機能**: 困った時はヒントを見られる
- 🎉 **楽しいUI**: カラフルでアニメーション豊富なインターフェース
- 📱 **レスポンシブ対応**: スマホでもPCでも快適に学習

## 🎓 学べるCSSプロパティ

1. **color** - 文字色の変更
2. **font-size** - テキストサイズの調整
3. **background-color** - 背景色の設定
4. **padding** - 内側の余白
5. **text-align** - テキストの配置
6. **border-radius** - 角丸の作成
7. **text-shadow** - テキストに影をつける
8. **border** - 枠線の設定
9. **transform** - 要素の変形（回転など）
10. **linear-gradient** - グラデーションの作成

## 🚀 使い方

1. ブラウザで `index.html` を開く
2. チャレンジの説明を読む
3. CSSエディタでコードを書く
4. 「✨ 適用する」ボタンでプレビュー
5. 「✅ チェック」ボタンで正解確認
6. 次のレベルに進む！

## 💻 技術スタック

- HTML5
- CSS3 (グラデーション、アニメーション)
- Vanilla JavaScript (フレームワーク不要)

## 🎮 遊び方のコツ

- まずは「💡 ヒント」ボタンを見てみよう
- CSSを書いたら「✨ 適用する」で確認
- 思い通りになったら「✅ チェック」で正解確認
- 困ったら「🔄 リセット」でやり直せるよ

楽しくCSSをマスターしよう！🌟
